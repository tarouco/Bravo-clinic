Raster crops of the Bravô Clinic lockup taken from the facade render (the only brand file so far). Draft use only; replace with the official vector files when they arrive.

- `bravo-wordmark-wall.png`: the horizontal lockup (BRAVÔ / CLINIC / — SALAS INTELIGENTES —) in backlit letters on the stone wall. For slides and mood boards.
- `bravo-sign-vertical.png`: the vertical blade sign with the Ô monogram above the lockup. For vertical formats and social avatars (crop to the monogram).

Both include their photographed background, so they cannot sit on other colors; show them as photos in a `radius-md` frame. In interfaces, set the name in type instead.
